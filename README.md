# LangChain Playlist

Code from the CampusX LangChain YouTube playlist, combined into a single repo.
Each folder is a copy of one of the tutor's original repos.

## Adding more repos

```bash
./add_repo.sh https://github.com/campusx-official/<repo-name>
```

This copies the repo into a new folder, adds it to the list below, commits and pushes.
